# Hangman (Python OOP)

A Hangman game built with Python's Tkinter library. This version uses Object-Oriented Programming (OOP) for clean, modular code and external JSON handling for word categories.

##  Features
1. External Word Bank: Loads categories (Movies, Countries, etc.) from a `words.json` file.
2. Dynamic GUI: Responsive keyboard, live hangman drawing, and category selection.
3. OOP Structure: Built using classes to ensure no global variable conflicts.

##  Installation & Usage
1. Clone this repository or download the ZIP.
2. Ensure you have the `words.json` file in the same directory as the script.
3. Run the game:
   ```bash
   python main.py
